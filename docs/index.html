Entendendo RTOS na prática

Materiais para apresentação, estudo e desenvolvimento com FreeRTOS — do conceito de tempo real até tarefas, filas e sincronização em sistemas embarcados. O conteúdo foi feito para ser apresentado ao vivo, mas pode ser acompanhado de forma assíncrona pela web também. Sinta-se livre para navegar pelos conteúdos, fazer exercícios e até mandar seu projeto para nossa comunidade e trocar ideia com outros membros sobre o seu projeto! :)
