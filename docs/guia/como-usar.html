Estrutura de pastas

docs/
├── index.html              # landing
├── assets/css/main.css     # design sample (tokens no :root)
├── modulos/                # aulas / capítulos
├── exemplos/               # demos de componentes e snippets
└── guia/                   # esta documentação do template

Adicionar uma página

  1. Copie modulos/01-introducao.html (ou um exemplo em exemplos/).
  2. Ajuste o <title>, eyebrow, h1 e o corpo em .content.
  3. Corrija os caminhos relativos do CSS e do menu (../assets/... vs assets/...).
  4. Inclua o link no menu do header e, se fizer sentido, na agenda do index.html.
  5. Atualize o .pager anterior/próximo entre módulos vizinhos.

Convenção sugerida

Prefixe módulos com número: 03-filas.html, 04-sincronizacao.html. Assim a ordem fica óbvia no repositório.

Trocar o design

O visual atual é um sample. Para redesenhar sem reescrever o HTML, edite só as variáveis CSS em docs/assets/css/main.css: 

:root {
  --bg: #0b1210;
  --accent: #3dd68c;
  --font-display: "Syne", system-ui, sans-serif;
  --font-mono: "IBM Plex Mono", ui-monospace, monospace;
  /* ... */
}

Classes estáveis para reutilizar: .hero, .callout, .pre-wrap, .btn, .pager, .toc. Veja demos em Exemplos.

Publicar no GitHub Pages

  1. No repositório: Settings → Pages.
  2. Source: Deploy from a branch.
  3. Branch: main (ou a branch padrão), pasta /docs.
  4. Salve. O site fica em https://<org-ou-user>.github.io/<repo>/.

Base path

Links neste template são relativos (modulos/..., ../assets/...), então funcionam tanto na raiz do Pages quanto em preview local via arquivo ou servidor estático.

Pré-visualizar localmente

Qualquer servidor estático na pasta docs/:

cd docs
python3 -m http.server 8080
# abra http://localhost:8080
