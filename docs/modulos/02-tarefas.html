Criando uma task

Cada task é uma função que tipicamente nunca retorna: ela entra em um loop e cede o CPU com delays ou bloqueios em filas/semáforos. 

/* Exemplo ilustrativo — ajuste ao seu port */
void vBlinkTask(void *pvParameters)
{
    (void)pvParameters;
    for (;;)
    {
        gpio_toggle(LED_PIN);
        vTaskDelay(pdMS_TO_TICKS(500));
    }
}

int main(void)
{
    xTaskCreate(
        vBlinkTask,
        "blink",
        configMINIMAL_STACK_SIZE,
        NULL,
        tskIDLE_PRIORITY + 1,
        NULL
    );
    vTaskStartScheduler();
    for (;;);
}

Prioridade

Números maiores = maior prioridade. Tasks de mesma prioridade compartilham o tempo conforme a configuração de time-slicing do port.
