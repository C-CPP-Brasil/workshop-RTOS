Módulo 01

O que é FreeRTOS?

Objetivo

Agora conheceremos o FreeRTOS, um sistema operacional RTOS muito usado no mercado de embarcados devido a sua leveza.

Contexto

O FreeRTOS é o sistema operacional de tempo real mais usado no mercado de embarcados, pois é leve, fácil de portar para diversas arquiteturas e provê uma API baseada em POSIX, que facilita o desenvolvimento de software até mesmo para os desenvolvedores entrantes no mercado.

Atenção

Apesar de dizermos que um STR executa tarefas com tempo limitado, isso não quer dizer que o programa deve ser curto, na verdade ele pode ter qualquer tamanho, inclusive o programa em si pode ser um loop infinito que só para ao dispositivo ser desligado.
