Criar uma task

Padrão para páginas de código curto + explicação

Assinatura típica de xTaskCreate. Os parâmetros exatos dependem do port e de FreeRTOSConfig.h. 

BaseType_t xTaskCreate(
    TaskFunction_t pvTaskCode,
    const char * const pcName,
    configSTACK_DEPTH_TYPE usStackDepth,
    void *pvParameters,
    UBaseType_t uxPriority,
    TaskHandle_t *pxCreatedTask
);

Notas para o instrutor

  • Mostre o retorno pdPASS / errCOULD_NOT_ALLOCATE_REQUIRED_MEMORY.
  • Compare stack depth em words vs bytes no port usado no lab.
